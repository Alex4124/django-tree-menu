# Django Tree Menu

Тестовое задание: реализация древовидного меню в Django.

## Описание

Django-приложение для создания древовидного меню с следующими возможностями:
- Меню реализовано через template tag
- Все родители активного пункта развернуты
- Первый уровень вложенности под активным пунктом также развернут
- Данные хранятся в БД
- Редактирование через стандартную админку Django
- Активный пункт определяется по URL текущей страницы
- На странице может быть несколько меню (определяются по названию)
- URL могут быть заданы явно или через named URL
- **Отрисовка меню требует ровно 1 запрос к БД**

## Технологии

- Python 3.x
- Django 5.x
- SQLite (база данных по умолчанию)

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <URL вашего репозитория>
cd django_tree_menu
```

2. Создайте виртуальное окружение и активируйте его:
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
# или
venv\Scripts\activate  # для Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Выполните миграции:
```bash
python manage.py migrate
```

5. Создайте суперпользователя:
```bash
python manage.py createsuperuser
```

6. Запустите сервер:
```bash
python manage.py runserver
```

7. Откройте админку и создайте меню:
```
http://127.0.0.1:8000/admin/
```

## Использование

В шаблоне используйте template tag:
```django
{% load menu_tags %}
{% draw_menu 'main_menu' %}
```

где `'main_menu'` - это slug меню из админки.

## Особенности реализации

- Используется `select_related()` для оптимизации запросов к БД
- Рекурсивная отрисовка меню в шаблоне
- Поддержка неограниченной вложенности пунктов меню
- Автоматическое определение активного пункта по URL
